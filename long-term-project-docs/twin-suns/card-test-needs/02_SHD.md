# SHD: multiplayer test needs

126 of the 210 reviewed SHD cards need Twin Suns or Always Two tests beyond the engine-level ones (see ../engine-test-notes.md). Cards not listed need none.

### Gar Saxon — Viceroy of Mandalore #001

> Each friendly upgraded unit gets +1/+0. // Each friendly upgraded unit gets +1/+0 and gains: “When Defeated: You may return an upgrade that was attached to this unit to its owner’s hand.”

**Always Two**
- Ensure the teammate's upgraded units also get +1/+0 on both sides.
- Ensure the teammate's upgraded units gain the deployed When Defeated ability, used by the teammate, and a returned upgrade goes to its owner's hand (the teammate, Gar Saxon's controller or an enemy).
