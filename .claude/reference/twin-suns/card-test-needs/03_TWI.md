# TWI: multiplayer test needs

128 of the 211 reviewed TWI cards need Twin Suns or Always Two tests beyond the engine-level ones (see ../engine-test-notes.md). Cards not listed need none.

### Nala Se — Clone Engineer #001

> Ignore the aspect penalty on Clone units you play. // Ignore the aspect penalty on Clone units you play. / Each friendly Clone unit gains: “When Defeated: Heal 2 damage from your base.”

**Always Two**
- Ensure the aspect penalty is not ignored on a Clone unit your teammate plays.
- Ensure, when deployed, the teammate's Clone units also gain the When Defeated ability, and it heals the teammate's base.

### Nute Gunray — Vindictive Viceroy #002

> Action [Exhaust]: If 2 or more friendly units were defeated this phase, create a Battle Droid token. // On Attack: Create a Battle Droid token.

**Always Two**
- Ensure defeated units of the teammate count toward the 2 friendly units defeated, combined with the controller's own.

### Yoda — Sensing Darkness #004
